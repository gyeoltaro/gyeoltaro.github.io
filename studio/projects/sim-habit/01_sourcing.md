# 01 소재선별팀 보고서

- **핵심 주제**: 새해 결심이 실패하는 진짜 이유 4가지와 습관 만드는 법
- **타깃**: 20~30대 직장인·학생, 자기계발에 관심 있지만 작심삼일을 반복하는 사람
- **수익화 적합도**: 8/10
  - 검색 수요가 꾸준하고 연초·월초마다 다시 오름 (에버그린)
  - 광고주 친화적 주제 (건강, 생산성, 교육)
- **저작권 / 재사용 콘텐츠 위험**: 중간 → 재각본으로 해소
  - 원문 문장을 그대로 읽으면 '재사용 콘텐츠' 위험이 있음
  - 대처: 캐릭터 대화극으로 구조를 바꾸고, 원문에 없는 사례·비유를 추가함
- **사실 확인 필요**: "연구자들은 ~라고 말한다" → 특정 연구 수치를 인용하지 않고 일반론으로 표현
- **분량 판단**: 롱폼 1편(약 8분) + 숏폼 3개로 충분함

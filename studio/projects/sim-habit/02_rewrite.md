# 02 재각본팀 결과

## 구성 (유지율 중심 재배열)
1. **후크**: 민수가 12번째 결심을 선언하는 장면 → 유나가 "2월이면 끝나"라고 받아침
2. **문제 제기**: 의지력 탓이 아니라 결심을 '설계'하는 방법이 틀렸다
3. **전개 4막**: 원문 순서를 바꿔 공감도가 높은 순서로 재배치
   - 너무 큰 목표 → 2분 규칙 (원문에 없던 '헬스장 등록만 하고 끝' 사례 추가)
   - 시간·장소 미정 → 습관 연결 (원문에 없던 '양치 뒤 플랭크' 예시 추가)
   - 결과만 봄 → 달력 체크 (원문에 없던 '게임 연속 출석 보상' 비유 추가)
   - 한 번 실패로 포기 → "이틀 연속만 피하기" 규칙
4. **반전**: 사실 가장 강력한 건 정체성. "나는 운동하는 사람이다"
5. **요약 + CTA**: 4가지 규칙 정리, 오늘 할 2분 행동 제안, 구독 유도

## 관점 추가
- 민수(실패 전문가)와 유나(현실 조언가)의 대화극
- 해설(narrator)이 핵심 규칙을 한 줄로 정리
- 원문 문장 복붙 0%. 사실 관계만 가져오고 문장은 전부 새로 씀

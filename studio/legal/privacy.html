Privacy Policy

Gyeoltaro Studio · Effective date: October 5, 2026

Gyeoltaro Studio ("the Studio") is a private content-production tool operated by the owner of the YouTube channel it publishes to. It renders cartoon videos and uploads them to that single channel. It has no other users and no public sign-up.

YouTube API Services

The Studio uses YouTube API Services. By using the Studio you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the Studio accesses

  • OAuth tokens for the channel owner's own Google account, with the scopes youtube.upload and youtube, used only to upload videos, set thumbnails and add videos to the owner's playlists.
  • Public YouTube data (video titles, view, like and comment counts, public comments, channel subscriber counts) retrieved with an API key, used only to produce research reports for the owner.

How the data is used, stored and shared

  • Data is used only to produce and publish videos on the owner's channel and to write internal research reports.
  • The OAuth refresh token is stored only as an encrypted environment secret of the owner's private build environment. It is never written to the source repository, logs or reports.
  • Public YouTube data in research reports is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies.
  • No data is sold, shared with third parties, or used for advertising.
  • The Studio does not use cookies or tracking technologies.

Revoking access

The owner can revoke the Studio's access at any time at Google Account › Security › Third-party access. On revocation, the stored token is deleted.

Gyeoltaro Studio · 시행일: 2026년 10월 5일

Gyeoltaro Studio(이하 "스튜디오")는 채널 운영자 본인이 자신의 YouTube 채널에 만화 영상을 제작·업로드하기 위해 쓰는 비공개 제작 도구입니다. 다른 사용자나 공개 가입은 없습니다.

YouTube API 서비스

스튜디오는 YouTube API 서비스를 사용합니다. 스튜디오를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. 구글의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

접근하는 데이터

  • OAuth 토큰: 운영자 본인 계정에 한해 youtube.upload, youtube 권한으로 영상 업로드, 썸네일 설정, 본인 재생목록 추가에만 사용합니다.
  • 공개 YouTube 데이터(영상 제목, 조회·좋아요·댓글 수, 공개 댓글, 채널 구독자 수): API 키로 조회해 운영자용 리서치 리포트 작성에만 사용합니다.

이용·보관·공유

  • 데이터는 운영자 채널의 영상 제작·게시와 내부 리서치 리포트 작성에만 씁니다.
  • OAuth 리프레시 토큰은 운영자의 비공개 빌드 환경에 암호화된 환경 변수로만 보관하며, 소스 저장소·로그·리포트에 기록하지 않습니다.
  • 리서치 리포트의 공개 YouTube 데이터는 YouTube API 서비스 개발자 정책에 따라 30일 이내에 갱신하거나 삭제합니다.
  • 데이터를 판매하거나 제3자와 공유하거나 광고에 쓰지 않습니다. 쿠키와 추적 기술을 쓰지 않습니다.

접근 권한 철회

운영자는 언제든 Google 계정 › 보안 › 서드 파티 액세스에서 권한을 철회할 수 있으며, 철회 시 보관 중인 토큰을 삭제합니다.

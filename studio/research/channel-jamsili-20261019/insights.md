# 잠실이 채널 점검 (2026-10-19, 공개 데이터)

출처: YouTube Data API (`research.py channel @jamsili`, `research.py topic 감동사연 --shorts --days 30`).
트래픽 소스·노출 클릭률·시청 지속·'스와이프하지 않고 본 비율'은 YouTube 스튜디오(애널리틱스)에만 있어 여기서는 볼 수 없음.

## 현재 숫자
| 항목 | 값 |
|---|---|
| 구독자 | 907 (10/5 902 → 2주 동안 +5) |
| 총 조회 | 약 3.0만 (영상 39개: 롱폼 10, 쇼츠 29) |
| 쇼츠 조회 | 대부분 900~1,900회에서 멈춤 (중앙값 약 1,100) |
| 사연 롱폼 조회 | 31~72회 (7편) |
| 실화 롱폼 3편 (8월) | 3~9회 |
| 좋아요율 | 쇼츠 0.0~0.7% (감동사연 쇼츠 중앙값 약 2.0%) |
| 댓글 | 39개 영상 모두 0개 (댓글 기능은 켜져 있음) |
| 쇼츠 → 롱폼 | 형제편: 쇼츠 4개 약 4,000회 → 롱폼 65회 (약 1.6%) |

## 읽히는 것
1. **쇼츠가 첫 시험 노출(약 1,000회)에서 매번 멈춤.** 노출 뒤 반응(좋아요·댓글·끝까지 보기)이 약해서 다음 단계로 안 퍼지는 패턴.
2. **반응이 기준의 1/5~1/10.** 좋아요율 0.3% 안팎, 댓글 0 — 보긴 했지만 감정이 움직이지 않았거나, 보자마자 넘긴 조회가 많을 가능성.
3. **구독으로 안 이어짐.** 쇼츠 3만 회에 구독 +5. "결말은 본편에서"로 끊는 구조가 쇼츠 시청자에게 만족감을 못 주는 것으로 보임.
4. **본편 링크 없음.** 쇼츠 설명에 「롱폼 제목」만 있고 주소가 없음(쇼츠 설명 링크는 눌리지 않지만, '관련 동영상' 연결은 꼭 필요).
5. **경쟁 쇼츠는 짧은 예고가 아니라 완결형.** 최근 30일 '감동사연' 쇼츠 상위권은 길이 중앙값 약 106초, 80% 이상이 1분 이상(최대 3분)인 완결형 이야기(#시니어사연 #인생이야기 #중년드라마). 10/6 조사(180일, 중앙값 36초) 이후 3분 쇼츠가 퍼지면서 흐름이 바뀐 것으로 보임. 단, 검색 결과 기반이라 표본이 편향될 수 있음.

## 다음에 바꿀 것 (제안)
1. 쇼츠 실험: 지금 형식(25초 예고) 2개 + **60~90초 완결 압축본** 2개를 같은 편에서 나란히 올려 비교.
2. 쇼츠 첫 1초에 대사 시작, 표지 0.35초도 없애 보기 → 스와이프 비율 확인.
3. 쇼츠마다 '관련 동영상'을 본편으로 연결하고 `publish.url` 채우기.
4. 영상 끝 질문을 더 구체적으로(“여러분이라면 A? B?” 양자택일) + 고정 댓글로 첫 댓글 유도.
5. 스튜디오에서 쇼츠별 **'스와이프하지 않고 본 비율'**과 롱폼 **트래픽 소스**를 확인해 위 가설 검증.

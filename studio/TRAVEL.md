# 여행 쇼핑쇼츠 (제휴 링크 수익화)

2026-10-07 시작. 여행지·숙소·투어 쇼츠를 만들어 **마이리얼트립 · 여기어때 · 쿠팡 파트너스** 제휴 링크로 수익을 냅니다.
도구는 `tools/travel.py`, 링크 페이지는 `/trip/` (https://gyeoltaro.github.io/trip/) 입니다.

## 한눈에 보기
```
사진 3~6장 (또는 AI 영상 클립) + 대사 4~6줄 ─▶ travel.py all ─▶ short.mp4 (15~30초, 9:16)
                                                     ├▶ kit.html (유튜브·인스타·네이버 클립용 제목/설명/캡션 복사)
                                                     └▶ trip/deals.json 에 번호 등록 ─▶ git push ─▶ 링크 페이지에 N번 표시
영상 끝: "프로필 링크에서 N번" ─▶ 시청자가 프로필 링크(/trip/) 에서 N번 검색 ─▶ 제휴 링크로 예약 ─▶ 수수료
```

**그대로 가져올 것**
1. 촬영·얼굴 없이 만드는 구조 → `travel.py` 가 사진 움직임·자막·음성·음악·끝 안내를 자동으로 만듭니다.
2. 링크는 프로필 하나로 모으고 영상에서는 **번호**만 말하는 방식 → `/trip/` 링크 페이지 (인포크링크 대신, 무료)
3. 한 영상을 유튜브 쇼츠 · 인스타 릴스 · 네이버 클립에 동시에 올리기 → 업로드 키트가 플랫폼별 문구를 만듭니다.

**바꿀 것**
1. **사진 출처**: 영상의 "숙소 사진 1장"은 대부분 숙소·예약 플랫폼의 저작물입니다. 허락 없이 쓰면 저작권 신고 → 영상 삭제·채널 경고 위험이 있습니다. 아래 '사진 규칙'만 따릅니다.
2. **수익 기대치**: 이 영상은 강의·자료 신청으로 이어지는 홍보 영상이고, 수익은 출연자의 주장입니다. 상위 댓글(22👍)도 "무료자료 준다고 해놓고 제대로 주는 사람 못봤네"였습니다. 아래 '수익 계산'으로 현실적으로 봅니다.
3. **광고 표시**: 화면·제목·설명에 모두 표시합니다 (자동).

## 세 플랫폼 (2026-10 검색 기준 — 가입 후 대시보드에서 실제 요율을 꼭 확인)

| | 마이리얼트립 파트너 | 여기어때 마케팅 파트너 | 쿠팡 파트너스 |
|---|---|---|---|
| 잘 맞는 상품 | 해외 투어·티켓·숙소 | 국내 숙소, 해외투어 | 여행 준비물(캐리어·압축파우치·어댑터) |
| 수수료 | 1~7% (숙소·티켓 약 2%, 해외 왕복 항공 1%, 국내 항공·보험·렌터카 0%) | 해외투어 최대 7%, 챌린지 상금·협찬 쿠폰 | 보통 약 3% (상품마다 다름) |
| 가입 | 블로그·인스타·유튜브 중 1개 등록, 승인 약 1일 | 파트너 신청 | 채널 등록 후 승인 (최종 승인은 실적 필요) |
| 정산 | 익월 25일, 최소 5만 원 | 대시보드 확인 | 대시보드 확인 |
| 필수 문구 | 대가성 표시 | 대가성 표시 | "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." |

**순서 추천**: 먼저 계정(인스타 또는 유튜브)을 만들고 영상 3~5개를 올린 뒤 → 마이리얼트립 → 여기어때 → 쿠팡 순서로 신청. 쿠팡은 영상마다 "이 여행에 챙길 것" 1개를 같이 걸어 두는 보조 수익으로 씁니다.

## 꼭 지켜야 할 4가지

### 1. 쇼츠의 링크는 눌리지 않는다 → 번호 + 프로필 링크
유튜브 쇼츠의 설명·댓글 링크는 클릭되지 않습니다(2023-08 변경). 인스타 릴스도 캡션 링크가 안 눌립니다.
그래서 영상 끝에 **"프로필 링크에서 N번"** 을 보여 주고, 프로필 링크에 `https://gyeoltaro.github.io/trip/` 를 넣습니다.
`/trip/#12` 처럼 번호를 붙이면 12번이 바로 강조됩니다.

### 2. 사진 규칙 (가장 중요)
| 쓸 수 있음 | 쓰면 안 됨 |
|---|---|
| 직접 찍은 사진·영상 | 예약 사이트·숙소 홈페이지·블로그·인스타에서 저장한 사진 |
| 숙소에 메일·DM으로 **사용 허락**을 받은 사진 (허락 메일은 보관) | 다른 유튜버 영상 캡처 |
| 한국관광공사 등 **공공누리 1유형** 사진 (출처 표시, 상업 이용 가능) | 공공누리 2·4유형 (상업 이용 금지) |
| 제휴사가 파트너용으로 제공한 홍보 소재 (제공 약관 범위 안에서) | 실제 숙소와 다르게 AI로 만든 사진 (기만 광고) |
| Unsplash·Pexels 같은 무료 라이선스 사진 — **분위기 컷에만** (특정 숙소인 것처럼 쓰지 않기) | 출처를 모르는 사진 |

`trip.json` 의 `credit` 에 출처를 적지 않으면 `lint` 가 막습니다. AI 영상 클립(구글 Flow·Veo·Kling)은 **권리가 있는 사진**으로만 만들고, 유튜브 업로드 때 '변경되었거나 합성된 콘텐츠: 예'로 설정합니다.

### 3. 광고 표시 (공정위 추천·보증 심사지침)
- 영상 화면: 왼쪽 위에 "광고 · ○○ 제휴 링크 포함" 이 내내 표시됩니다 (자동)
- 설명·캡션 첫 줄 `[광고]` + 플랫폼별 대가성 문구 (업로드 키트가 자동 작성)
- 유튜브: '유료 프로모션 포함' 체크 / 인스타: 유료 파트너십 라벨 또는 `[광고]`
- 링크 페이지 맨 위와 맨 아래에 안내 문구 (적용됨), 링크에는 `rel="sponsored"`
- 가격은 **확인한 날짜**와 함께. "최저가 보장", "무조건 최저" 같은 근거 없는 말은 쓰지 않습니다 (`lint` 가 경고)

### 4. 채널은 따로
사연 만화 채널(@jamsili)에 여행 쇼츠를 섞으면 시청자층이 달라 두 채널 모두 추천이 약해집니다. 여행용 유튜브·인스타·네이버 클립 계정을 새로 만듭니다.
여행 쇼츠 수익은 제휴 수수료가 중심이라 유튜브 파트너 프로그램 없이도 시작할 수 있습니다. 다만 사진만 바꾼 똑같은 영상은 '반복적인 콘텐츠'로 보일 수 있으니, 대사에 그 숙소만의 정보(가격·위치·팁·주의점)를 넣습니다.

## 영상 공식 (travel.py 기본값)
| 구간 | 내용 |
|---|---|
| 0~2초 | 큰 후크 2줄(줄당 13자 이하) + 펀치 줌, 첫 대사에 **가격 또는 장소** ("1박 9만 원대에 이 노을 실화예요?") |
| 2~25초 | 컷 4~6개, 컷마다 2~4초, 노란 꼬리표(인피니티풀·조식 포함 등), 숫자는 노란 자막 |
| 마지막 2.6초 | 숙소명 · 가격(확인일) · **"프로필 링크에서 N번"** 버튼 |
| 내내 | 광고 표시, 진행 막대, 코드로 작곡한 배경음악(저작권 없음), 컷 전환 효과음 |

좋은 소재: ① 가격 대비 놀라운 곳 ("1박 9만 원 오션뷰") ② 시즌 (단풍·벚꽃·크리스마스·연휴 3주 전) ③ 지역 TOP3 ④ 해외 투어 한 가지 ("다낭 바나힐 줄 안 서는 법")

### trip.json
| 키 | 설명 |
|---|---|
| `slug` | 폴더 이름과 같게 |
| `platform` | `myrealtrip` / `yeogi` / `coupang` |
| `link` | 파트너 대시보드에서 만든 제휴 링크 |
| `name`, `region`, `tags` | 링크 페이지에 표시 |
| `price`, `price_checked` | "1박 9만원대부터", "2026-10-07" — 14일 지나면 경고 |
| `hook` | 첫 화면 2줄 |
| `shots[]` | `img`(사진) 또는 `clip`(mp4), `line`(대사), `tag`(꼬리표), `motion`(`in`/`out`/`left`/`right`/`up`, 없으면 자동), `caption`(자막을 대사와 다르게) |
| `end_shot` | 마지막 안내 뒤에 깔 컷 번호 (기본: 마지막 컷) |
| `credit` | 사진 출처 (필수) |
| `music` | `hope`/`warm`/`calm` … · `music_volume` |
| `voice` | `gvoice`(Google Chirp3-HD 음성), `edge`, `rate` |
| `publish` | `title`, `description`, `hashtags` |
| `deal_id` | 비워 두면 `all`/`deal` 이 새 번호를 매기고 기록 |
| `video_url` | 올린 뒤 쇼츠 주소 (선택) |

## 링크 페이지 `/trip/`
- 데이터: `trip/deals.json` (사이트 이름 `site_name`, 소개 `intro`, `youtube`·`instagram` 주소, `deals[]`)
- 번호·이름·지역 검색, 지역 버튼, 라이트/다크 모드, 플랫폼별 버튼 색
- 링크가 비어 있으면 "링크 준비 중"으로 표시 (https 링크만 허용)

- **지금은 무료 GitHub Pages 로 충분합니다**: `https://gyeoltaro.github.io/trip/`

## 수익 계산 (현실적으로)
| 예시 | 계산 | 1건 수익 |
|---|---|---|
| 국내 숙소 10만 원 (마이리얼트립 숙소 약 2%) | 100,000 × 2% | 약 2,000원 |
| 해외 투어 10만 원 (최대 7%) | 100,000 × 7% | 약 7,000원 |
| 캐리어 8만 원 (쿠팡 약 3%) | 80,000 × 3% | 약 2,400원 |

월 50만 원 ≈ 건당 3,000원 × 약 170건. 보통 클릭의 1~3%가 예약으로 이어진다고 보면 월 클릭 6천~1.7만 번이 필요합니다.
그래서 **단가 높은 상품(해외 투어·패키지·고급 숙소)** 과 **시즌 소재**가 중요하고, 한 영상을 세 플랫폼에 올려 노출을 늘립니다.

## 남은 일 (사용자)
1. 여행용 유튜브·인스타 계정 만들기, 이름 정하기 → `trip/deals.json` 의 `site_name` 바꾸기
2. 세 플랫폼 파트너 가입 (계정 1개 + 영상 몇 개가 있어야 승인이 쉬움)
3. 프로필 링크에 `https://gyeoltaro.github.io/trip/` 넣기
4. 첫 소재 3개 고르고 사진 확보 → Claude 에게 trip.json 작성·렌더링 요청

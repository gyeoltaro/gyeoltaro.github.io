# 사연 영상 노하우 (롱폼·쇼츠 필수 요소)

2026-10-06 조사. 모든 부서는 대본을 쓰기 전에 이 문서를 읽고, 렌더링 전에 `python3 studio/tools/studio.py lint <project.json>` 으로 점검합니다.

## 조사 근거
- YouTube Data API (`research.py topic`, 최근 180일, 한국): `사연툰`·`시어머니 사연`·`사연 만화`(롱폼), `감동 사연`·`사연 애니`(쇼츠). 각 상위 30~50개의 제목·길이·업로드 시각·설명·태그·댓글을 비교했습니다.
- 웹 자료: 유튜브 공식 도움말(중간광고), 업계 가이드(시청 지속·쇼츠·제목 테스트), 수익 정책(비진정성 콘텐츠).
- 한계: 썸네일 이미지 서버(i.ytimg.com)는 이 환경의 네트워크 정책에 막혀 이미지를 직접 비교하지 못했습니다. 영상 자체도 볼 수 없어서 메타데이터·설명·댓글로만 분석했습니다.

## 롱폼 필수 요소
1. **0:00 하이라이트** (15~30초): 절정 대사 2~4개를 먼저 보여 주고 본편을 시작합니다. 결말은 숨깁니다. 상위 영상 챕터가 `00:00 하이라이트`로 시작합니다. → `teaser` 로 지정
2. **첫 20초 안에 충격**: 효과음과 함께 놀람·충격 대사를 넣고, "이 이야기를 하려면…" 식으로 회상에 들어갑니다.
3. **60~90초마다 주의 환기**: 반전, 질문, 효과음, 배경 전환 가운데 하나. 한 장면은 75초 이하로 하고, 이어지는 장면끼리는 배경을 다르게 합니다.
4. **시점 표시**: 회상은 세피아 톤과 "20년 전" 같은 표시를 붙입니다. 시간이 뛰면 시청자가 길을 잃습니다. → `flashback`, `when`
5. **대사 위주** (해설 45% 이하): 해설만 이어지면 슬라이드쇼처럼 보이고, '비진정성 콘텐츠'(대량·반복 생산물)로 판정될 위험이 있습니다.
6. **판단을 부르는 갈등**: 댓글 상위는 "남편은 왜 가만있냐", "시어머니가 선을 넘었다" 같은 인물 평가입니다. 누가 옳은지 말하고 싶게 만드는 장면이 댓글을 늘립니다.
7. **맺음**: 시청자에게 질문(댓글 유도) + '창작 사연'/'실화' 표시 + 20초 이상의 잔잔한 장면(최종 화면 자리).
8. **중간광고**: 자동 배치 + 장면 경계 수동 추가를 함께 씁니다. 유튜브 발표 기준으로 둘을 섞은 채널의 광고 수익이 평균 5% 넘게 높습니다. → 업로드 키트가 위치를 추천

## 쇼츠 필수 요소
0. **본편으로 넘어오게 연결 (실측 2026-10-09)**: 롱폼 조회는 대부분 쇼츠에서 넘어오는데, 넘어오는 비율이 0.6~3%였습니다. 롱폼을 올리면 `publish.url` 에 링크를 넣어 쇼츠 설명과 고정 댓글에 본편 링크가 들어가게 하고, 쇼츠마다 **관련 동영상**을 본편으로 꼭 설정합니다. 쇼츠 끝에는 "아래 링크 누르면 결말" 화살표와 음성 안내(`shorts_cta_line`)가 자동으로 붙습니다.
1. **첫 프레임 = 표지**: 큰 후크 2줄(줄당 13자 이하) + 감정 얼굴 + 소품. 첫 2초에 넘기는 비율이 노출을 결정합니다.
2. **바로 갈등 대사로 시작**: 설명 해설 없이 충돌·충격 대사부터 시작합니다. → `clips`
3. **20~28초**: 감동 사연 상위 25%의 중앙값은 24초입니다. 짧을수록 끝까지 보는 비율과 다시 보는 비율이 올라갑니다.
4. **반복 재생 엔딩**: 마지막에 표지를 다시 보여 주면 첫 프레임과 이어져 자연스럽게 다시 재생됩니다(다시 보기는 강한 추천 신호). → `shorts_loop` (기본 켜짐)
5. **결말은 본편에서**: 반전 직전에 끊고 `end_text` + 관련 동영상(롱폼)을 연결합니다.
6. **제목**: 해시태그 2개 안팎, 괄호·숫자 없이 사건 한 줄 (상위 쇼츠는 괄호 0%, 숫자 0%).

## 제목·설명·썸네일
- **제목 공식**: ① 「상황 + 결과」 (예: 매주 반찬 보내는 시어머니가 귀찮았는데, 반찬통 바닥을 보고 무너졌습니다) ② 「“대사”… + 상황」 (예: “네 엄마가 뭘 가르쳤니?”… 김장하다 장갑을 벗은 며느리)
- **제목도 A/B 테스트**: 테스트 및 비교로 제목 3개 × 썸네일 3개를 시청 시간 기준으로 비교할 수 있습니다(2025년 12월 전 세계 확대). → `publish.title_variants` 에 2개 더
- **설명**: 사건 요약(따옴표 대사 1~2개) → 챕터 → "여러분이라면 어떻게 하셨을까요?" → 창작·합성 표시 → 해시태그 3~5개
- **썸네일**: 감정 얼굴 클로즈업 + 반전 소품 + 빨간 원·화살표 + 2줄(노란 강조). 소품 글자는 영상 속 실제 정보로 씁니다(낚시 금지).

## 정책 (수익 창출 유지)
- 대량·반복 생산 판정을 피하려면 영상마다 인물·배경·구도·소품이 달라야 하고, 이야기 구조도 바꿔야 합니다.
- 합성 음성 사용 → 업로드할 때 '변경되었거나 합성된 콘텐츠: 예'로 설정합니다.
- 창작 사연은 영상 끝과 설명 두 곳에 모두 표시합니다.

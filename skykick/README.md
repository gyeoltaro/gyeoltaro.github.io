# 하늘 발차기

움직이는 송판을 밟고 하늘 끝까지 뛰어오르는 2D 태권도 점프 아케이드 게임입니다. 어울림 태권도 버전입니다.

- 주소: https://gyeoltaro.github.io/skykick/
- 파일 하나(`index.html`)로 동작하고, 그래픽과 효과음, 배경음악을 모두 브라우저에서 직접 그리고 연주합니다.
- 랭킹전은 무한의 격파와 같은 Firebase 프로젝트(`infinite-gyeokpa`)의 `skykick_ranking` 컬렉션에 따로 저장됩니다.

## 게임 방법

| 조작 | 동작 |
|---|---|
| 점프 버튼, 화면 터치, Space · ↑ · W | 모아 뛰기 |
| 공중에서 한 번 더 | 뛰어 옆차기 (조금 더 떠오름) |
| 공중에서 또 한 번 | 540 발차기 (한 번 더 떠오름, 점프마다 발차기는 2번까지) |

- 좌우로 움직이는 송판에 내려앉으면 한 층 올라갑니다. 점수는 올라간 층수입니다.
- 뛰어오르는 순간 밟고 있던 송판은 부서집니다. 다음 송판을 놓치면 떨어져서 끝납니다. 맨 처음 도장 마당에서는 놓쳐도 다시 뛸 수 있습니다.
- 한 송판에 오래 서 있으면 금이 가다가 부서집니다. 화면 위 **발판** 게이지가 남은 시간입니다.
- 송판 가운데에 정확히 내리면 **기합** 게이지가 찹니다. 꽉 차면 6초 동안 조금 빗나가도 송판에 붙는 자석 착지가 됩니다.
- 올라갈수록 송판이 빨라지고 좁아지며, 하늘이 낮 → 노을 → 밤 → 우주로 바뀝니다.

| 발판 | 특징 | 나오는 높이 |
|---|---|---|
| 송판 | 기본 발판 | 처음부터 |
| 겹송판 | 빨랐다 느렸다 속도가 바뀜 | 16층부터 |
| 기와 | 좁고 빠름 | 41층부터 |
| 황금 송판 | 밟으면 위의 송판 4장을 발차기로 격파하며 5층 슈퍼 점프 | 8층부터 가끔 |

띠는 층수로 승급합니다: 노란띠 10층, 초록띠 25층, 파란띠 45층, 빨간띠 70층, 품띠 100층, 검은띠 1단 140층부터 9단까지.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 |
| `firebase-config.js` | Firebase 웹 설정값 (무한의 격파와 같은 프로젝트) |
| `firestore.rules` | 랭킹 보안 규칙. 무한의 격파 5개 도장과 하늘 발차기를 모두 담은 공용 규칙입니다 |

## 랭킹전 켜기 (한 번만)

Firebase 프로젝트와 익명 로그인, 승인된 도메인은 무한의 격파 때 이미 설정되어 있습니다. 새 컬렉션의 보안 규칙만 올리면 됩니다.

1. https://console.firebase.google.com 에서 `infinite-gyeokpa` 프로젝트를 엽니다.
2. **빌드 > Firestore Database > 규칙** 탭에서 기존 내용을 모두 지우고 `firestore.rules` 내용을 그대로 붙여 넣은 뒤 **게시**합니다.
   - 이 파일에는 기존 무한의 격파 규칙 5개가 그대로 들어 있고 `skykick_ranking` 규칙만 추가되어 있어서, 통째로 바꿔도 기존 랭킹은 그대로 동작합니다.

규칙을 올리기 전에는 랭킹 화면에 "랭킹전은 준비 중이에요"가 표시되고, 게임은 그대로 할 수 있습니다.

## 다른 도장 버전 만들기

`index.html`의 스크립트 맨 위 `DOJANG` 설정만 바꾸면 됩니다.

```js
const DOJANG = {
  name: '어울림 태권도',      // 도장 현판 글씨
  key: 'skykick',             // 이 기기에 최고 기록·설정을 저장하는 이름
  col: 'skykick_ranking',     // 랭킹전 Firestore 컬렉션
};
```

- `key`와 `col`은 도장마다 다르게 정합니다. 예: 한성태권도는 `skykick_hansung`, `skykick_hansung_ranking`.
- 새 `col` 이름은 `firestore.rules`에도 같은 모양의 `match` 블록으로 추가하고 다시 게시해야 랭킹이 켜집니다.

## 운영 메모

- **무료 사용량:** 게임을 한 번 열 때 랭킹 상위 100개를 읽습니다. 무한의 격파와 같은 프로젝트라 하루 무료 읽기 5만 건을 함께 씁니다.
- **기록 삭제:** Firebase 콘솔 **Firestore Database > 데이터 > skykick_ranking**에서 해당 문서를 지우면 됩니다.
- **점수 조작 방어:** 로그인 없는 게임이라 완전히 막을 수는 없습니다. 보안 규칙은 형식, 범위(10만 층 이하), 자기 기록만 더 높은 점수로 갱신하는 조건을 검사합니다.
